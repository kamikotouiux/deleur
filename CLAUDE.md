# Проект: сайт студии Deléur

## Имя
- Название: **Deléur** (с акцентом в вордмарке и заголовках).
- В URL, email, хэндлах, метаданных — без акцента: deleur. Акцент в домене не использовать.
- В тексте страницы писать единообразно «Deléur». Студия — «Deléur», не «Deléur Studio», если не решено иначе.

## Контекст
- Независимое дизайн-агентство, два равных со-основателя: Val Anpilogov (бренд, кампании, арт-дирекшн) и Daniel Kurilenko (продукт, веб, digital). Оба — Co-founder & Creative Director.
- Цель сайта: точка приземления для теста ~12 гипотез лидогенерации (рефералы, партнёрства, outreach, соцсети, концепты, полезные продукты). Внутренняя кухня эксперимента на сайте не упоминается.
- Отдельно от Design Punks и SixCat.
- Язык сайта: английский.

## Зафиксировано
- Стек: код (собираем через Claude Code). Хостинг — Vercel (подключён).
- Визуальную систему задаёт Daniel: от простого сэмпла, который он сделает сам.
- Одна страница, 7 секций + футер: Hero → Selected work → What we can make → How we get there → You'll know who's making it → A few things worth asking → Contact → Footer.
- Работы: 8 кейсов (4 Val + 4 Daniel), единое портфолио агентства. Подпись: название, 1–2 категории, одно предложение (10–25 слов) о задаче. Без недоказанных цифр, отзывов, наград.
- Услуги как в брифе: брендинг и упаковку закрываем полностью.
- Основателям одинаковое визуальное равенство: размер портрета, заголовка, длина био.
- CTA: «Talk about your project» → контакт; «See our work» → блок работ. Кнопка формы: «Send project details».
- Цены не публикуются: объясняем, из чего складывается стоимость.
- Доп. блок доверия (логотипы, отзывы) — отложен до первых результатов.

## Форма (отличия от landing-brief.md выделены)
- Обязательно: имя, email, описание проекта.
- Опционально: компания/сайт, бюджет, сроки.
- **Опционально: «How did you hear about us?»** — выпадающий список (Referral / Partner agency / Social media / Outreach message / Our concept or tool / Search / Other) + свободный текст для Other. Значения согласовать со списком гипотез.
- **Скрыто: UTM-метки и referrer** сохраняются вместе с заявкой (из URL при первом заходе).
- **Срок ответа** показать рядом с формой (например, «We reply within 2 business days») — срок не согласован, см. открытые вопросы.
- Успех показывать только после реальной доставки, при ошибке сохранять введённое.
- Рядом с кнопкой — короткая ссылка на Privacy notice. Чекбокс согласия не нужен.

## Доставка заявок
- Заявки уходят в общий Telegram-чат основателей через бота: serverless-функция на Vercel → Telegram Bot API (sendMessage).
- Токен бота и chat_id — только в переменных окружения Vercel, не в коде.
- Сообщение: все поля формы + «How did you hear» + UTM/referrer + время.
- Успех на сайте показывать только после ответа Telegram API «ok».
- Резерв: при ошибке Telegram дублировать заявку на email студии (чтобы заявка не терялась молча).
- Защита от спама: honeypot-поле + простой rate limit.
- Заявки разбирают оба основателя. Кто берёт заявку — ставит реакцию в чате, чтобы не ответить дважды или не пропустить.

## Приватность (ЕС)
- Без cookies и трекеров, требующих согласия: никакого Google Analytics, Meta Pixel, Hotjar. Тогда cookie-баннер не нужен.
- Аналитика: только cookieless (Plausible, Fathom или Vercel Web Analytics).
- Шрифты хостить локально, не грузить с Google Fonts CDN.
- Видео кейсов — свои файлы, а не встроенный YouTube (или youtube-nocookie + клик для загрузки).
- Страница или блок Privacy notice: кто отвечает за данные (имя/компания + email), что собираем (данные формы), зачем (ответить на запрос), где хранится (сервис формы/почта), как долго, как запросить удаление.

## Принципы дизайна
- Работа — главное доказательство. Интерфейс достаточно спокойный, чтобы оценить студию, прочитать кейс и связаться.
- Но не безликий: нужно одно узнаваемое «поведение» (типографика/композиция/сетка), которое работает в hero, обложке кейса и маленьком соцпревью.
- Тексты, навигация и форма стабильны при любом визуальном приёме. Всё работает с отключённым motion.
- Референс по подходу к кейсам и сеткам: zajno.com.
- **Направление (согласовано 13.11.2026):** простой editorial/галерейный стиль, как в музеях и на выставках. Без сложных шрифтовых решений и графики (нет времени и бюджета на «вау»). «Дорого» — за счёт дисциплины: сетка, пустота, типографика, качество медиа работ. Изюминка допустима, но небольшая.
- Три территории из brand-naming-brief.md (A/B/C) больше не действуют.
- Рефы направления: yeezy.com, zajno.com, prodco.xyz, a24films.com, blahblahblah.design (+ /alexander_gladkikh/), charmerstudio.com/ru/grid, charmerstudio.com/ru/work/art-of-cinema.

## Процесс (каждый этап утверждает человек; одна сессия — один этап)
1. Визуальное направление от сэмпла Daniel.
2. Wireframe: подача 7 секций, в первую очередь блок работ.
3. Концепты: 3 варианта hero / работ / услуг — реально разные по композиции и цвету.
4. Финализация: стайлгайд, компоненты, состояния (кнопки, ссылки, форма, ошибки, фокус).
5. Сборка и деплой.
