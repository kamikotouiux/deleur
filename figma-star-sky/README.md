# Starry Sky Plugin — локальный плагин для Figma

Генерирует звёздное небо из Drop shadow (приём, как у Wiza): каждая звезда — тень почти невидимой точки (fill 0.2%).
Figma позволяет максимум 8 Drop shadow на слой, поэтому плагин сам раскладывает звёзды по точкам по 8 штук.

## Установка (один раз)

1. Скачай папку `figma-star-sky` (`manifest.json`, `code.js`, `ui.html`).
2. Открой **Figma desktop** (в браузере dev-плагины не ставятся).
3. **Plugins → Development → Import plugin from manifest…** → выбери `manifest.json`.
4. Запуск: **Plugins → Development → Starry Sky Plugin**.

## Как пользоваться

1. Выдели **Frame** или **Component** (не Instance).
2. Плагин сам выберет пресет: «Секция» для больших фреймов, «Кнопка» для маленьких.
3. **Сгенерировать** → дальше крути ползунки, звёзды обновляются сразу.
4. **Перемешать** — новая раскладка с теми же настройками.
5. Настройки хранятся в слое `★ Stars`: выдели фрейм позже — плагин их подтянет.

## Ползунки

| Группа | Ползунок | Что делает |
|---|---|---|
| Насыщенность | Плотность | Сколько звёзд. Считается от размера фрейма (∝ √площади), поэтому 50% одинаково выглядит и на секции, и на кнопке |
| | Яркость | Множитель прозрачности всех звёзд |
| Точки | Форма | **Круги**, **Искры** (четырёхлучевые, как у Telegram) или **Микс**: мелкие — круги, средние и крупные — искры |
| | Выпуклость искры | Видна, когда выбраны искры. 2% — тонкие иглы, 10% — как Telegram, 25% — ровный ромб, выше — выпуклые грани |
| | Размер | Размер самых мелких (дальних) звёзд |
| | Разброс размера | Во сколько раз ближние крупнее дальних. ×1 — плоско, ×3 — глубина |
| | Размытие | Layer blur ближних звёзд. От 2 размываются и средние |
| Расположение | Кучность | 0 — равномерно, выше — скопления вдоль диагональной полосы |
| | Отступ от края | Не даёт звёздам прилипать к краям (важно для кнопок) |
| Цвет | Основной / Акцент / Доля акцента | Часть звёзд можно окрасить вторым цветом |

Под ползунком плотности видно, сколько звёзд получится и какого размера.

## Почему так, а не «N звёзд на фрейм»

Слой разбит на три плана глубины в пропорции 65 / 25 / 10%:

| План | Размер | Яркость |
|---|---|---|
| Дальние | размер | 35–80% |
| Средние | между | 60–100% |
| Ближние | размер × разброс, с блюром | 85–100% |

Контраст между мелкими тусклыми и крупными яркими звёздами и даёт «дорогой» вид. Одинаковые точки 1px выглядят плоско.

## Нюансы

- Звёзды раскладываются не чистым random, а «лучшим из кандидатов»: для каждой пробуется 8–16 мест и берётся самое свободное. Сначала ставятся крупные, потом мелкие заполняют промежутки. Поэтому даже 10–15 звёзд на кнопке ложатся равномерно, без кучек и дыр, но и не сеткой.
- В углы, которые срезает скругление фрейма, звёзды не ставятся.

- Искры автоматически крупнее кругов (×3, минимум 3px): у них тонкие лучи, и меньше 3px форма превращается в точку. Подсказка под плотностью показывает реальные размеры, искры помечены ✦.

- Слой `★ Stars` вставляется самым нижним ребёнком фрейма. Если фон у тебя отдельным слоем (картинка, прямоугольник), перетащи `★ Stars` выше него.
- Поменял размер фрейма — нажми «Сгенерировать» ещё раз.
- 300+ звёзд = много эффектов, Figma может подтормаживать.
