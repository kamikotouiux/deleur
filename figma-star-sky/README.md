# Star Sky — локальный плагин для Figma

Генерирует звёздное небо из Drop shadow (приём, как у Wiza): каждая звезда — тень почти невидимой точки.
Figma позволяет максимум 8 Drop shadow на слой, поэтому плагин сам раскладывает звёзды по точкам по 8 штук.

## Установка (один раз)

1. Скачай папку `figma-star-sky` (три файла: `manifest.json`, `code.js`, `ui.html`).
2. Открой **Figma desktop** (в браузере dev-плагины не ставятся).
3. Меню → **Plugins → Development → Import plugin from manifest…** → выбери `manifest.json`.
4. Плагин появится в **Plugins → Development → Star Sky**.

## Как пользоваться

1. Выдели **Frame** или **Component** (не Instance), в котором нужно небо.
2. Плагин сам подставит пресет: «секция» для больших фреймов, «кнопка» для маленьких. Количество звёзд пересчитывается под площадь фрейма.
3. Нажми **Сгенерировать**.
4. Крути ползунки — звёзды обновляются сразу. **Перемешать** — новая случайная раскладка с теми же настройками.
5. Настройки сохраняются в слое `★ Stars`: выдели фрейм позже — плагин подтянет их обратно.

## Три слоя глубины

| Слой | Пресет «секция» (1440×760) | Пресет «кнопка» (180×44) |
|---|---|---|
| Дальние | 160 шт, 1px, яркость 35–80% | 16 шт, 1px, 50–100% |
| Средние | 64 шт, 2px, 60–100% | 8 шт, 1.5px, 70–100%, blur 1 |
| Ближние | 24 шт, 3px, 85–100%, blur 1 | выкл |

Именно разница в размере и яркости между слоями даёт глубину. Один слой 1px выглядит плоско и тускло.

## Нюансы

- Слой `★ Stars` вставляется самым нижним ребёнком — над заливкой фона, под контентом. Если у тебя фон сделан отдельным слоем (картинка, градиент-прямоугольник), перетащи `★ Stars` выше него.
- **Отступ** не даёт звёздам прилипать к краю — полезно для круглых кнопок.
- Если поменял размер фрейма — нажми «Сгенерировать» ещё раз.
- Много звёзд = много эффектов. На 300+ звёзд Figma может подтормаживать.
